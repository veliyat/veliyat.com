Optivo Health

Tech Lead · Nov 2025 – present

Take product tour

Optivo is digital eye exam record software for independent optometry practices in South Africa. It is in its final stage before launch.

I am the primary technical owner of the application.

What the product does

  • Exams that follow the optometrist's own flow, built from modules that can be included or left out
  • Structured digital clinical records in place of paper and free-text notes
  • Reports and referrals created from the exam record and saved to the patient file
  • Feedback notes, scans, fundus photos and additional tests saved to the patient file, with next steps kept visible
  • AI dictation that turns the clinician's spoken notes into structured exam data and clinical notes

Tools: React 18, TypeScript, Vite, Tailwind CSS, shadcn/ui, Radix UI, React Router, TanStack Query, Supabase, PostgreSQL, Google Speech-to-Text, Gemini on Vertex AI, Vitest, React Testing Library, Playwright.

How I work: Claude Code supports design, implementation and review. Design decisions and code review stay with me.

AI Coding Tutor

open source · Fightrons

Try AI Coding Tutor

Source on GitHub

An adaptive AI programming tutor that teaches JavaScript step by step. I built it as an open-source demo project under Fightrons.

What it does

  • Learners start without registering and can resume on any device with an access code
  • Lessons run in an in-browser code editor that executes JavaScript and checks each solution with automated tests
  • An AI tutor gives hints instead of answers, and offers help when a learner is stuck

How it is organised: feature modules (auth, layout, lesson, editor, tutor), thin route pages, and a shared layer for UI components, utilities and types.

Tools: React, TypeScript, Tailwind CSS, shadcn/ui, Supabase (Auth, Postgres with Row-Level Security, Edge Functions), OpenAI GPT-4o-mini, Monaco Editor, Vitest, Playwright.
